## 1. Meta uses AI to decide which ad request gets how much computer power
*Meta Engineering* · Backend / AI

**In one line:** Meta built a system that gives extra computer power to the ad requests that gain the most from it, and it gets better ads out of the same machines.

**What happened:** Showing an ad takes computer power, and there is never enough. Some ad requests gain a lot from extra power. Others gain almost nothing. Meta used to sort requests into big groups and give each group a fixed rule. That did not scale. So Meta trained an AI model, the "Resource Core Model", to guess for each request how much it would gain. Then three layers make choices: which data center region serves it, which kind of chip runs it, and how much of one machine it gets. Meta says the system added about 10% better ad ranking from 2017 to mid-2026. AI agents now propose and test changes too. They did about 20% of the optimization work in early 2026, and about 80% on the most automated part. Engineers still approve every change.

**Why it matters:** When hardware is scarce, spending it wisely can matter as much as buying more.

**New words:** **Marginal utility** — how much extra benefit one more unit of something gives · **Latency** — how long a request takes to get an answer · **MTIA** — Meta's own custom AI chip

## 2. Shopify lets AI agents attack its own live systems, with a second AI watching
*Shopify Engineering* · Security

**In one line:** Shopify built "Cyber Chaos Monkey", an AI hacker that tests its real production systems, plus a second AI that can shut it down.

**What happened:** Shopify's bug bounty program (where outsiders get paid for finding flaws) has seen about 300% more reports since 2024, because AI makes finding bugs cheap. Shopify decided to use the same tools on itself first. Its agents get test shop logins and know the code and the setup. They have run tens of thousands of attack attempts and found dozens of real problems, with no outage. To keep it safe, the attacker runs in a locked container with no special rights. It can only reach a short list of websites. A "judge" AI, from a different model, reads everything the attacker does. If the judge sees a rule broken, it kills the attacker at once. If the judge crashes or goes quiet, the run stops too.

**Why it matters:** Attackers now use AI. Companies that know their own systems best can use AI to find holes before anyone else.

**New words:** **Production** — the real, live system customers use · **Chaos engineering** — breaking things on purpose to learn how they cope · **Egress** — traffic leaving a network · **Rules of Engagement** — the written limits on what the tester may do

## 3. Netflix maps how its systems connect so AI can find the cause of an outage
*InfoQ (about Netflix)* · Backend / AI

**In one line:** Netflix is building a "knowledge graph", a map of how its apps, alerts and deployments relate, so engineers and AI can investigate problems faster.

**What happened:** Netflix handles more than 2 billion requests a day. When something breaks, finding why can take about four hours. The clues are spread over many tools, like alerts, deploy records and chat. Most of the time goes to piecing together how things connect. So Netflix wrote a shared model of these things and links, and stored it in its own database, QuipuDB. Programs called enrichers fill it in. Some use plain rules and some use AI, but strict checks limit the AI's output. A correlation engine looks at 13 kinds of signals, such as errors, deployments and config changes, and ranks likely causes. Netflix's AI root-cause system, AutoRCA, shares the same map. Humans still approve fixes.

**Why it matters:** AI helpers work better when they share one clear picture of how a company's systems fit together.

**New words:** **Knowledge graph** — a map of things and how they are linked · **Ontology** — an agreed list of the kinds of things and links in a map · **Root cause** — the real reason a problem happened · **Observability** — being able to see what a system is doing from the data it gives off

## 4. Meta gets Android's "real device" test phone running on Apple laptops
*Meta Engineering* · Mobile / Tooling

**In one line:** Meta ported Cuttlefish, a very realistic virtual Android device, to Macs with Apple chips, so developers can use one test device everywhere.

**What happened:** Developers test apps on virtual devices called emulators. Meta's Reality Labs, which makes AI glasses, used two. Goldfish ran on Macs but was less like the real device. Cuttlefish was more realistic but only ran on Linux. Keeping both was costly and confusing. So Meta brought Cuttlefish to macOS. It revived support for QEMU (software that runs a virtual machine), made Linux-only parts build on Mac, raised a memory-tracking limit for Apple's hypervisor, and added a native display and code signing. Meta shared its QEMU fork and patches for others. It also says AI agents can use these virtual devices to test code.

**Why it matters:** Testing on a faithful copy of the device catches bugs earlier and needs fewer scarce real devices.

**New words:** **Emulator** — software that pretends to be a phone or device · **Hypervisor** — the layer that lets a computer run virtual machines · **vhost-user** — a way to run virtual device parts as separate programs

## 5. Discord on Linux now updates itself and shares your screen the modern way
*Discord* · Desktop

**In one line:** Discord rebuilt its Linux app with a self-updater and better screen sharing for Wayland.

**What happened:** Linux users had to download a new package every week. Now a small installer puts Discord in your home folder, and a new Rust updater changes it without needing admin rights. Updates are "delta" patches, so only changed bytes download. Discord measured them about 23% faster. For screen sharing, Wayland (the newer Linux display system) asks you before sharing. Discord then uses your graphics chip to compress the video. It works on the Steam Deck too. Push-to-talk now works on Wayland. Discord is also working with Igalia to let you share one app's sound, not the whole desktop.

**Why it matters:** It shows how much work it takes to make one app feel at home on many kinds of Linux.

**New words:** **Wayland** — a newer Linux system for drawing windows, stricter about privacy · **Delta update** — an update that sends only what changed · **Hardware encoding** — using the graphics chip to compress video

## 6. Cloudflare releases Kitesurf, a light web browser built for AI agents
*Cloudflare* · AI / Cloud

**In one line:** Cloudflare made its agent-focused browser open source, so anyone can run it.

**What happened:** AI agents need to load web pages and click around. Full browsers like Chromium use a lot of CPU and memory. Kitesurf runs on Cloudflare Workers (small programs that run on Cloudflare's network) with no browser container. It reads the page, applies styles, runs the page's JavaScript and takes screenshots. It speaks the Chrome DevTools Protocol, so tools like Puppeteer can connect. It uses open Rust parts such as Blitz, Stylo and Boa. You can run it locally or deploy it to your own Cloudflare account on a paid plan. Cloudflare says it is still changing quickly.

**Why it matters:** A cheaper browser makes it easier to run many agents at once.

**New words:** **Open source** — code anyone can read and change · **Chrome DevTools Protocol** — a standard way for tools to control a browser · **WebAssembly** — a format that lets fast code run safely in many places

[Read the full post →](https://blog.cloudflare.com/kitesurf-open-source/)

## 7. llama.cpp reaches version 1.0 and promises stable interfaces
*Hugging Face* · AI

**In one line:** The popular tool for running AI models on your own computer hit version 1.0.0.

**What happened:** llama.cpp lets people run language models on everyday hardware. After 3.5 years, many apps depend on it. So the team released v1.0.0 of llama.cpp and its engine ggml. From now on, a breaking change to the public C interface means a new major version number. New features bump the minor number, and bug fixes the patch number. It now ships through Docker, Homebrew, Winget and more. It supports over 150 model designs. The team says it uses AI tools carefully and wants to stay in control of the code.

**Why it matters:** Developers building on it can now trust version numbers to warn them of breakage.

**New words:** **API** — the set of ways programs talk to a library · **Semantic versioning** — numbering that shows whether a change breaks things · **Inference** — running a trained AI model to get answers
