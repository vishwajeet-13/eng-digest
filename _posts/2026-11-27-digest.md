## 1. AWS Lambda now lets one run last 30 minutes, double the old limit
*InfoQ* · Cloud

**In one line:** Amazon's pay-per-run code service raised its time limit from 15 minutes to 30.

**What happened:** AWS Lambda lets you run a small piece of code without managing any servers. Each run has a time limit, and it has been 15 minutes since 2018. Now it is 30 minutes. It applies in all commercial regions, at normal prices, and you just change a setting on each function. AWS says AI agent requests that chain many steps, video conversion, simulations and big reports were running out of time. Think of it like a parking meter that now lets you stay twice as long. But the article warns to check a few things first.

**Why it matters:** Longer runs need twice the capacity at the same traffic, and queues, retries and cost all need a second look. One expert says 30 minutes is the wrong fix for slow code behind a website.

**New words:** **Timeout** — the longest a job may run before it is stopped · **Concurrency** — how many copies of your code run at the same time · **Queue (SQS)** — a waiting line that holds jobs until code is ready · **Dead-letter queue** — a bin for jobs that keep failing

## 2. OpenAI and Cisco release Shirudo, a "shield" for Linux servers you can't patch yet
*OpenAI* · Security

**In one line:** Shirudo is a free tool that adds a temporary safety block to a running server while the real fix is prepared.

**What happened:** Fixing a security hole can take days or weeks. Meanwhile, blocking the dangerous action could also break normal requests. Shirudo uses eBPF, which lets tiny programs run safely inside the Linux core. A temporary guard, called a shield, is tested first and then loaded without restarting the service. In one test, a shield made with OpenAI's Codex blocked an attack on a running Elasticsearch service, which kept working. Shields are signed, checked by Linux, and recorded using a hardware chip. The code is open source.

**Why it matters:** Teams get protection in the gap between "bug found" and "patch installed", and others can reuse shields.

**New words:** **eBPF** — a way to run small, safe programs inside the Linux core · **Shield** — a temporary guard against one attack · **Patch** — the official fix for a bug · **TPM** — a hardware chip that keeps a trustworthy record

## 3. Cloudflare lets any website offer a search box that AI agents find on their own
*Cloudflare* · AI

**In one line:** Flip one switch and your site gets a search address built for AI agents.

**What happened:** Cloudflare's AI Search already could index a website. Now "Search for Agents" sets it all up from a toggle in the dashboard. It crawls your pages and serves search from your own domain. Every page also carries small hints in its header that tell agents where the search address is and how to use it. Instead of reading page after page, an agent asks one question and gets matching text back. Answers come as plain text, not a written reply, because the agent already has its own AI. It also supports a new web method called QUERY. It is open to all customers, including Free, with limits.

**Why it matters:** Agents get answers faster, and site owners still control access with their normal bot and firewall settings.

**New words:** **Agent** — an AI program that does tasks for you · **Index** — an organized list for fast searching · **Markdown** — simple plain text with light formatting · **QUERY** — a new web request type for safely sending search questions

## 4. GitHub dropped a styling method and made its pages render 55% faster
*InfoQ* · Frontend

**In one line:** After three years, github.com moved how it styles pages from code-based to plain stylesheets.

**What happened:** GitHub used "CSS-in-JS", where the look of a button is written inside JavaScript and built while the page loads. As pages grew to have many parts, this got slow. GitHub switched to CSS Modules, where styles live in normal files built ahead of time. The team did it piece by piece, hiding each change behind a flag and checking it with screenshot tests. About 7,760 style spots had to be rewritten. The last 895 took two engineers three weeks with AI coding helpers. Server page building got 55% faster.

**Why it matters:** Doing work once when you build, not every time someone visits, makes pages quicker. Some readers doubt the user impact.

**New words:** **CSS** — the language that sets how web pages look · **CSS-in-JS** — writing styles inside JavaScript · **CSS Modules** — style files whose names stay local to one part · **SSR** — building the page on the server before sending it

[Read the full post →](https://www.infoq.com/news/2026/11/github-css-migration/)

## 5. A QCon talk argues most teams already stopped really reading code in reviews
*InfoQ* · Career

**In one line:** A speaker says line-by-line code review is fading and teams need new ways to trust code.

**What happened:** Ankit Jain, who runs a company selling such tools, said so himself and asked people to be suspicious. He pointed to studies where reviewers wanted to find bugs, yet only 14% of comments were about bugs. A study of 4,000 teams found over 75% of changes merge with no human review. He proposed six steps: argue, capture, codify, prove, debate and own. For example, repeated review comments become standing rules. His nine-person team merges four times more changes and reverts dropped about 40%. But one change caused an 18-minute outage. Risky areas like billing still get line-by-line review.

**Why it matters:** When AI writes code fast, understanding it becomes the hard part.

**New words:** **Code review** — teammates reading a change before it ships · **PR (pull request)** — a proposed code change · **Revert** — undoing a change that broke things · **Invariant** — a rule that must always hold

## 6. Rust 1.100 finally ships the "never" type after ten years
*InfoQ* · Languages

**In one line:** The Rust language added a way to say "this code never returns a value".

**What happened:** Rust is a language known for safe, fast programs. Version 1.100 is its first with three digits. The headline is the never type, written `!`, for things like a crash or an endless loop. It took ten years and five failed tries. Rust also stabilised the base of custom memory allocators. Cargo, its package tool, gained an opt-in "cooldown" that holds back brand-new package versions, for example three days, as defence against malicious releases. Critics note it should not delay urgent security fixes.

**Why it matters:** The cooldown idea helps guard against poisoned packages.

**New words:** **Type** — a label saying what kind of value something is · **Allocator** — code that hands out memory · **Cargo** — Rust's package and build tool · **Crate** — a Rust package
