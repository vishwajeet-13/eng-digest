## 1. Outlook.com started bouncing email from domains with no DMARC record
*MailRoute* · Security

<video controls playsinline preload="none" poster="https://vishwajeet-13.github.io/eng-digest-videos/2026-11-09/1.jpg" src="https://vishwajeet-13.github.io/eng-digest-videos/2026-11-09/1.mp4"></video>

**In one line:** Since 5 November, Microsoft's free mail service has been turning away some email from domains that don't have a DMARC record, even from small senders.

**What happened:** Email has three checks that prove a message really came from who it says. SPF lists which servers may send for a domain. DKIM adds a digital signature. DMARC ties them to the "From" address and tells receivers what to do on a failure. MailRoute says Outlook.com, Hotmail, Live and MSN began rejecting some mail from domains with no DMARC record on 5 November. The bounce says "550 5.7.1 Message rejected: Message lacks SPF/DKIM/DMARC Auth Records". Microsoft has not announced it. Only some messages bounce, so a sender can think everything is fine. The fix is one DNS record: `v=DMARC1; p=none`, added under the name `_dmarc`.

**Why it matters:** Invoices or appointment reminders to people with personal Outlook addresses can vanish without anyone noticing. Checking takes seconds.

**New words:** **DMARC** — a public note that says how a domain's email should be checked · **DNS record** — a line in a domain's public settings · **p=none** — "report problems, but don't block anything"

## 2. How Cloudflare's database service handles millions of databases
*Cloudflare Blog* · Backend / Cloud

<video controls playsinline preload="none" poster="https://vishwajeet-13.github.io/eng-digest-videos/2026-11-09/2.jpg" src="https://vishwajeet-13.github.io/eng-digest-videos/2026-11-09/2.mp4"></video>

**In one line:** Cloudflare rebuilt the "management side" of its D1 database so people can create millions of small databases without slowing down queries.

**What happened:** D1 is Cloudflare's database service, built on SQLite. Apps made with AI tools often want many tiny databases, one per user or project. Cloudflare says live databases grew 15x in a year and daily active ones grew 18x. To cope, queries skip the central Postgres database entirely and go straight to the database's own copy near the user. Routing facts are kept in Workers KV, a store copied around the world. Every 30 seconds each database checks in with Postgres, so mistakes in creating or deleting get fixed on their own. Usage counts are queued and added up in batches so a flood of writes can't swamp Postgres.

**Why it matters:** It shows a handy rule: keep the busy path away from one central spot, and let the system repair itself.

**New words:** **Control plane** — the part that creates, deletes and tracks things, not the part that answers queries · **Idempotent** — safe to repeat; doing it twice gives the same result · **Heartbeat** — a regular "I'm alive, here's my state" message

## 3. Pinterest found how to train its recommendation AI longer without it "memorizing"
*Pinterest Engineering* · AI

**In one line:** Pinterest learned to let part of its model sit still for a while, so training it for more rounds helps instead of hurts.

**What happened:** Pinterest's feed model uses huge tables that turn each Pin into a list of numbers. Training them for two rounds instead of one made results about 6% worse, because the tables memorized examples instead of learning patterns. Freezing the tables fixed that, but then they could not adapt. The team found timing mattered: keep the tables frozen for the first round, then let them learn in the last round. They also sped up training by fetching the next batch's data while the GPUs worked on the current one. The result was about 1.09% more saves in live tests.

**Why it matters:** Different parts of one AI model may need different training schedules.

**New words:** **Epoch** — one full pass through the training data · **Embedding** — a Pin turned into a list of numbers · **Overfitting** — memorizing examples instead of learning general patterns

## 4. systemd will now accept Rust — but only in small programs
*Amutable Blog* · Open source / Languages

**In one line:** systemd, a core part of many Linux systems, merged support for writing pieces in Rust, with strict limits.

**What happened:** systemd starts and manages programs on Linux and has long been written in C. It now allows Rust in separate small programs, but not yet in its shared core library. The reason: Rust lacks good support for shared libraries, so each of the 180+ programs would carry duplicate code. Rust programs must act exactly like the C ones, use systemd's build tool instead of cargo, and add few outside packages. Old, stable C code won't be rewritten without a good reason, and Rust stays optional.

**Why it matters:** It's a careful way to add a new language to a huge, old project.

**New words:** **systemd** — the program that starts and manages other programs on many Linux systems · **Shared library** — code many programs use together · **Crate** — a Rust code package

## 5. Dropbox says AI coding helpers let it ship a three-year project on time
*Dropbox Tech* · AI / Career

**In one line:** Dropbox describes how engineers handed defined jobs to AI agents and then reviewed the work.

**What happened:** Dropbox is rolling out a new experience that answers questions about files and can reorganize them. To bring web features to the desktop app, it shared React components between both. Agents helped trace dependencies and write the glue code. Each task started with a written plan, then the agent made changes and ran tests, and an engineer reviewed the result. Agents helped deliver 22 accessibility features. A cleanup put off for two quarters was split into 53 tasks and done in one week.

**Why it matters:** The pattern here is clear tasks, clear rules, and human review.

**New words:** **Coding agent** — an AI that writes and tests code on its own · **Accessibility** — making software usable with a screen reader or keyboard · **Adapter** — code that connects a shared feature to a specific app
